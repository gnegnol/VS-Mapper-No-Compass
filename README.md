# Mapper Map No Compass

This is a patch that removes the need for a compass in the map recipe from 
Genhis's mod Mapper, because I feel like you don't need a compass to create a map.

## Acknowledgments

I based this (and realized it was achievable for me) thanks to **Dryophoenix**
and their patch [Mapper Map Recipe Patch](https://mods.vintagestory.at/mappermaprecipepatch).

## Dependencies

Mapper:
- [GitHub](https://github.com/Genhis/VintageStoryMods)
- [VSMODDB](https://mods.vintagestory.at/mapper)
